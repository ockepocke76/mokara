# 💹 Assets

Simulations are driven by asset return models. Two kinds of models are
available:

## Parametric models

Returns are drawn from a statistical distribution defined by an expected
annual return (μ) and volatility (σ), optionally with fat tails and
autocorrelation. Parametric models are useful for exploring "what if" asset
assumptions directly.

## Bootstrap models

Returns are resampled from real historical index data (block bootstrap), which
preserves the empirical distribution of returns — including crashes, rallies,
and volatility clustering — without assuming normality. The library includes
decades of history for major world indices (S&P 500, NASDAAQ, DAX, OMX, Nikkei
and many more) plus Bitcoin.

Each asset's model and parameters are shown when you select it on the
[simulate page](/simulate). Details of how models feed the simulation are in
the [methodology](/docs/methodology).
